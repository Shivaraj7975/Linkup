====================================================================
               LINKUP PROJECT - TEAMMATE SETUP GUIDE
====================================================================

Follow these quick steps after pulling the latest updates from GitHub:

--------------------------------------------------------------------
1. PULL LATEST CODE & INSTALL DEPENDENCIES
--------------------------------------------------------------------
git pull origin main

# Update backend dependencies
cd server
npm install

# Update frontend dependencies
cd ../client
npm install


--------------------------------------------------------------------
2. DATABASE UPDATE (Add AI Matches Cache Table)
--------------------------------------------------------------------
Run the updated database schema file or execute this SQL command 
in your PostgreSQL database (linkup_db):

psql -U postgres -d linkup_db -f server/src/db/schema.sql

-- Or manually run this SQL in PGAdmin / psql:
CREATE TABLE IF NOT EXISTS matches (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    input_hash VARCHAR(64) NOT NULL UNIQUE,
    linkup_id UUID NOT NULL REFERENCES linkups(id) ON DELETE CASCADE,
    results JSONB NOT NULL,
    generated_by VARCHAR(50) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);


--------------------------------------------------------------------
3. UPDATE ENVIRONMENT VARIABLES (server/.env)
--------------------------------------------------------------------
Copy the new AI provider configuration variables from server/.env.example 
into your local server/.env file:

# AI Waterfall Configuration
AI_PROVIDER_ORDER=groq,nvidia_llama,voidai,nvidia_nemotron,gemini
AI_PROVIDER_TIMEOUT_MS=7000
AI_PROVIDER_COOLDOWN_MS=60000

# AI Provider API Keys
GROQ_API_KEY=your_groq_api_key_here
NVIDIA_LLAMA_API_KEY=your_nvidia_llama_api_key_here
VOIDAI_API_KEY=your_voidai_api_key_here
NVIDIA_API_KEY=your_nvidia_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here


--------------------------------------------------------------------
4. (OPTIONAL) SEED TEST CANDIDATES
--------------------------------------------------------------------
To populate 100 realistic student candidate profiles for AI matching:

node server/src/db/seed_100_candidates.js


--------------------------------------------------------------------
5. START THE APP
--------------------------------------------------------------------
# Terminal 1 - Backend Server
cd server
npm run dev

# Terminal 2 - Frontend Client
cd client
npm run dev

Open http://localhost:5173 in your browser!
